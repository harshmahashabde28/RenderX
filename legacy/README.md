# Archived project material

The application is built from `renderx/app.py`, `renderx/dashboard.py`, and the
active renderer, maze, challenges, and shooter modules under `renderx/`.

This directory preserves older UI experiments, unused audio and timing helpers,
design notes, generated package metadata, and the original shooter snapshot.
Archived files are retained for project history; the application and package
build do not load them.

The active, integrated shooter is in `renderx/shooter/`. Its credits and the
upstream license are recorded alongside that implementation.
