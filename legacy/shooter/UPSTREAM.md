# Shooter code and asset acknowledgement

RenderX's **Breakpoint** mode incorporates and adapts code and 3D assets from
[3D-RPG-Shooter](https://github.com/dev-mojammel-hosain/3D-RPG-Shooter), by
Mojammel Hosain Jesan, Rakib Chowdhury, and Abrar Mahir Chowdhury. The project
owner authorized this use for the RenderX project. The source repository's
`LICENSE` is retained here; its terms remain applicable to the upstream work.

RenderX changes include a resizable in-app launch flow, corrected viewport
aiming, input-driven firing, collision and cover handling, endless wave
progression, run persistence, and a redesigned interface. Upstream models,
textures, and core OpenGL rendering concepts remain credited to their authors.
