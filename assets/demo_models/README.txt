RenderX OBJ showcase models

Open any .obj file using Open OBJ in RenderX. These five lightweight models are designed to fit the current OBJ loader limits and make clear wireframe examples.

- coupe.obj — low-poly vehicle with separate faceted wheels
- rocket.obj — launch vehicle with fins and nose cone
- pine_tree.obj — layered low-poly tree
- torus.obj — parametric quad surface
- robot.obj — assembled block-built character

All meshes are original procedural showcase geometry.
