# UI icon assets

RenderX uses a small selection of SVG icons from [Lucide](https://lucide.dev/),
downloaded from the project's official `lucide-icons/lucide` repository. The
source icons are retained as SVG files and tinted at runtime to match the active
theme. Lucide is distributed under the ISC license; see [`LICENSE`](LICENSE).

The bundled Lucide files are `axis-3d`, `box`, `camera`, `chevron-down`,
`chevron-right`, `circle-question-mark`, `eye`, `folder-open`, `maximize-2`,
`minus`, `moon`, `move-3d`, `panel-left-close`, `panel-left-open`, `panel-right-close`,
`panel-right-open`, `play`, `plus`, `rotate-ccw`, `sun`, `volume-2`, `volume-x`,
and `x`.

`renderx-mark.svg` is RenderX's own RX monogram. The Explore object list uses
small isometric wireframe previews projected from each model's actual mesh.
